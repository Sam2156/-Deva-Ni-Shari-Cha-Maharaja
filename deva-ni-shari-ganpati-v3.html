One-time setup needed

Your Firebase config is already in this file. Two things still need doing in the Firebase console before it works:

  1. Build → Authentication → Email/Password → Enable.
  2. Build → Firestore Database → Create database (production mode), then in the Rules tab paste the rules block shown near ADMIN_EMAILS in this file's code, swap in your 2 real admin emails, and Publish.
  3. Back in Authentication → Users → Add user, manually create the 2 admin accounts (same 2 emails) with a password each. Do this here rather than via the site's sign-up, so only your 2 people ever get in.
